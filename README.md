# Graph Digitizer — Оцифровщик графиков

Десктопное приложение для оцифровки номограмм и графиков. Позволяет загрузить изображение графика, расставить опорные точки, получить их реальные координаты и экспортировать результат в CSV-файл.

---

## Возможности

- Загрузка изображений в форматах PNG, JPG, JPEG
- Калибровка осей координат по трём опорным точкам
- Добавление точек левой кнопкой мыши
- Перетаскивание точек для корректировки положения
- Удаление точек правой кнопкой мыши
- Предпросмотр аппроксимирующей кривой поверх изображения
- Сохранение нескольких графиков за одну сессию
- Экспорт координат всех графиков в CSV-файл
- Поддержка отрицательных значений осей

---

## Стек технологий

- **Python 3.10+**
- **tkinter** — графический интерфейс
- **matplotlib** — отображение изображения и обработка событий мыши

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/DrummerRed/Graph-digitizer.git
cd Graph-digitizer
```

2. Установите зависимости:
```bash
pip install requirements.txt
```

3. Запустите приложение:
```bash
python Graph_digitizer.py
```

> tkinter входит в стандартную библиотеку Python и не требует отдельной установки.

---

## Как пользоваться

1. **Открыть изображение** — загрузите файл с графиком или номограммой
2. **Калибровка осей** — кликните поочерёдно три точки: начало координат, максимум X, максимум Y; затем введите их реальные значения
3. **Добавить точки** — активируйте режим расстановки точек и кликайте по кривой графика
4. **Предпросмотр** — постройте линию через точки поверх изображения, чтобы проверить точность оцифровки
5. **Сохранить график** — сохраните текущий набор точек в память (можно повторить для нескольких кривых)
6. **Экспортировать в файл** — запишите все сохранённые графики в CSV

### Управление точками
| Действие | Результат |
|---|---|
| ЛКМ по пустому месту | Добавить точку |
| ЛКМ + перетащить | Переместить точку |
| ПКМ по точке | Удалить точку |
